# 🧠 12장. LangGraph와 상태 관리

이 장에서는 LangGraph를 활용해 대화 상태를 유지하고, 도구 호출을 포함한 에이전트형 워크플로우를 구성하는 방법을 실습합니다. 단순한 프롬프트 응답이 아니라, 그래프 기반으로 상태를 관리하며 여러 단계의 논리를 연결하는 방식을 학습합니다.

## 🧪 실습 내용

- LangGraph의 기본 개념 이해
- 상태를 가진 그래프 노드 구성
- 대화 메모리와 세션 상태 유지
- 도구 호출을 포함한 워크플로우 설계
- LangGraph 기반 에이전트 흐름 구현

## 🔍 핵심 개념

### 1. LangGraph 기본

그래프 구조를 사용해 각 단계가 어떤 입력과 출력을 가지는지 명확하게 표현합니다. 대화 흐름을 노드와 엣지로 나누어 상태를 관리하는 방식은 복잡한 에이전트 로직을 구조적으로 설계하는 데 유리합니다.

### 2. 상태 관리

메시지 기록, 사용자 상태, 이전 답변, 추론 결과 등을 그래프 상태에 저장하여 다음 단계에서 재사용할 수 있습니다. 이를 통해 대화가 이어지는 환경에서도 일관된 응답을 유지할 수 있습니다.

### 3. 도구 호출

LangGraph 안에서 계산, 검색, API 호출 같은 외부 도구를 연결하여 단순 질의 응답이 아니라 실제 업무 수행형 에이전트로 확장할 수 있습니다.

## 💡 학습 포인트

- 상태 관리가 필요한 이유를 실습을 통해 체감할 수 있습니다.
- 에이전트는 단순히 답변 생성 모델이 아니라, 여러 단계의 상태 전이를 관리하는 구조입니다.
- LangGraph는 로직 흐름을 시각적으로 이해하기 쉽게 만들어 복잡한 에이전트 시스템을 설계하는 데 적합합니다.
