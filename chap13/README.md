# 🧭 13장. LangGraph 기반 RAG

이 장에서는 LangGraph로 질문에 따라 처리 흐름을 나누는 RAG 애플리케이션을 구성합니다. 질문이 문서 지식을 필요로 하는지 먼저 라우팅하고, 검색 문서의 관련성을 평가한 뒤 답변을 생성합니다. 일상 대화는 별도의 노드에서 처리합니다.

## 🧪 실습 내용

- 9장에서 준비한 PDF와 Chroma 벡터 저장소 재사용
- 질문을 `vectorstore` 또는 `casual_talk`으로 분류하는 구조화 출력 라우터 구성
- 벡터 저장소에서 관련 문서 검색
- 문서 평가기로 질문과 관련된 검색 결과만 선별
- 검색 문맥을 바탕으로 RAG 답변 생성
- LangGraph의 상태, 노드, 시작점, 종료점 및 조건부 엣지 연결
- 그래프를 컴파일하고 질문을 입력해 실행

## 🗂️ 파일 구성

| 파일 | 설명 |
| --- | --- |
| `chap13_1_rag_with_langgraph.ipynb` | 라우팅, 문서 검색·평가, 답변 생성을 연결한 LangGraph RAG 실습 |
| `pyproject.toml` | 챕터 의존성 및 Python 버전 요구사항 |
| `uv.lock` | 고정된 패키지 버전 정보 |


## 🔍 그래프 흐름

```text
START
	└─ 질문 라우팅
			 ├─ vectorstore → 문서 검색 → 관련성 평가 → 답변 생성 → END
			 └─ casual_talk → 일상 대화 응답 → END
```

## 💡 학습 포인트

- 조건부 엣지로 질문 유형에 따라 서로 다른 노드 흐름을 실행할 수 있습니다.
- 검색 결과를 그대로 사용하지 않고 관련성을 평가해 불필요한 문서를 걸러냅니다.
- 그래프 상태를 각 노드가 읽고 갱신하면서 여러 단계를 하나의 워크플로우로 구성합니다.
